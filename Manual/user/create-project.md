# 新建项目

1. 打开 **Flare 引擎**启动器，点击 **新建项目**。
2. 将 **模板** 设为 **基础 3D 示例**。在 **项目名称** 输入 `MyFirstGame`，点击 **浏览…** 选择存放项目的父目录。
3. 核对 **最终目录**。例如父目录选了 `D:\FlareProjects`，项目就会建在 `D:\FlareProjects\MyFirstGame`。点击 **创建**，等待编辑器打开。

进入编辑器后，左侧 **场景层级** 中应能找到 `Main Camera`、`Directional Light`、`Ground` 和 `Cube`。下次启动 Flare 时，双击最近项目中的 `MyFirstGame` 即可继续。
