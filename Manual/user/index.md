# Flare 使用者文档

准备一个 `.fbx` 模型，启动 Flare，跟着下面四步完成第一次预览。如果刚克隆了仓库，可以先[从源码启动编辑器](build-from-source.md)。

1. [新建项目](create-project.md) · 用「基础 3D 示例」创建自己的项目。
2. [编辑器界面](editor-interface.md) · 在场景中找到立方体，查看它的属性。
3. [导入 FBX](import-fbx.md) · 把自己的模型加入项目，在资源列表里确认导入结果。
4. [运行预览](run-preview.md) · 运行当前场景，试一次暂停和单步，再回到编辑。
