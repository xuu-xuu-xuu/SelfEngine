# 项目入口、启动进度与编辑器外壳

## 进程和项目归属

[RunEditorLauncher()](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorLauncher.cpp#L763) 管理项目选择，[ProjectWorkspaceSession](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/ProjectWorkspaceSession.h#L56) 处理模板、预检和最近项目。[ProjectLease](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/ProjectWorkspaceSession.h#L37) 获取项目占用权，[RunEditorWorker()](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorWorker.cpp#L320) 接管打开后的项目。Windows 图形入口的 [ShowDebugConsole 开关](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Tools/SelfEngineEditor.cpp#L15) 控制开发控制台。

## 真实进度如何到达窗口

[ReportStartup()](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/PlatformLayer/Windows/StartupProgress.cpp#L40) 发布启动阶段，[StartupProgressChannel](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/PlatformLayer/Windows/StartupProgress.h#L20) 传递进度和取消信号。[EditorLoadingScreen](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorLoadingScreen.h#L11) 管理独立加载窗口，[DrawLoadingRibbon()](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/LoadingRibbon.cpp#L60) 按当前进度绘制金色飘带。窗口图标通过 [ApplyAppIcon()](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/PlatformLayer/Windows/AppBranding.cpp#L13) 设置。

## 默认 Toolkit 与 ImGui 路径

[RunEditorApp()](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorApplication.cpp#L215) 将会话、输入与渲染器装配到窗口宿主。默认 [EditorShell](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorUi/EditorShell.h#L48) 拥有面板和菜单，[EditorCommandRouter](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorUi/EditorCommandRouter.h#L21) 将快捷键送到 [EditorCommandBus](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorUi/EditorCommand.h#L48)。另一条 [ImGuiEditor](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/ImGuiEditor.h#L68) 路径将 ImGui 的顶点和批次复制成渲染数据，布局通过 [EditorDockLayout](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorDockLayout.h#L12) 保存。Toolkit 的布局树持久化由 [EditorDockState](https://github.com/xuu-xuu-xuu/FlareEngine/blob/e7ca801292037b33172d094cc4a434682ac83c9c/Source/ToolLayer/Editor/EditorUi/EditorDockState.h#L12) 完成，见[面板吸附](docking.md)。
