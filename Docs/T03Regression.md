## 当前模块定位

| 位置 | 职责 |
|---|---|
| Source/Sandbox/main.cpp：main | 控制台初始化、运行练习、调用应用、返回退出码 |
| Source/Sandbox/SandboxApp.cpp：RunSandboxApp | 持有组件，组织每轮调用顺序和收尾；选择 dt 上限 |
| Source/Platform/Windows/Window.cpp：PumpWindowMessages | 读取/分发线程消息，返回是否继续和退出码 |
| Source/Platform/Windows/WindowsInput.cpp：ProcessWindowsInput | 将消息转为状态和事件，保留默认行为 |
| Source/Platform/InputState.h：ClearEvents | 本轮消费者读完后清理事件，不清除按住状态 |
| Source/Platform/Windows/FrameTimer.cpp：UpdateFrameTimer | 测量实际时间与计数 |
| Source/Sandbox/SandboxDiagnostics.cpp：ObserveInput、ObserveTiming | 只读记录日志，内部保存自己的观察历史 |

模块边界检查已通过：观察不修改输入或计时，清理事件不依赖观察器，消息泵能交回退出码。该检查不创建窗口，不替代上面的真实交互。
